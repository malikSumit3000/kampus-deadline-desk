# Creator Badge Design

## Goal

Make the creator attribution clearly visible when the dashboard opens without distracting from deadline work.

## Placement

Place a dedicated creator badge in the sidebar directly below the Kampus brand and above the private-pilot label. Remove the small duplicate attribution at the bottom of the sidebar.

## Visual treatment

- Use the existing saffron accent with a subtle translucent border so it belongs to the current design system.
- Display `Built by Sumit Malik` as the prominent line.
- Display `Class of 2028` as the smaller supporting line.
- Keep the badge non-interactive and responsive within the existing sidebar/mobile layout.

## Scope and safety

- CSS and sidebar markup only; no user data, authorization, database, or Gmail behavior changes.
- Verify lint and production build before deployment.
